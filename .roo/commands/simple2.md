# Simple2

## Executable Wrapper

An executable wrapper script is available at [.roo/commands/simple2.sh](.roo/commands/simple2.sh). This wrapper:
- Resolves the workspace root automatically
- Invokes the target script with all arguments
- Forwards environment variables
- Propagates exit codes

You can invoke it directly:
```bash
./.roo/commands/simple2.sh [options]
```

## Usage

```

```
