## Executable Wrapper

An executable wrapper script is available at [.roo/commands/simple.sh](.roo/commands/simple.sh). This wrapper:
- Resolves the workspace root automatically
- Invokes the target script with all arguments
- Forwards environment variables
- Propagates exit codes

You can invoke it directly:
```bash
./.roo/commands/simple.sh [options]
```

## Usage

```
/simple [options]
```
